# Intertax CRM demo

View-only sample of the staff CRM and the client portal. Coworkers open the GitHub Pages link and click through it. They cannot edit CRM data. A temporary Hebrew suggestion layer lets them pin notes on the CRM page.

- Client portal: https://chananyaniasoff.github.io/intertax-crm-demo/portal.html
- Suggestions inbox: https://chananyaniasoff.github.io/intertax-crm-demo/suggestions.html
